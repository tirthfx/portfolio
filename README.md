# portfolio

Tirth's portfolio — https://tirthfx.github.io/portfolio/

Next.js (static export) + Tailwind + shadcn. Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm install
npm run dev     # http://localhost:3000/portfolio
npm run build   # static site in out/
```

Design notes live in the `portfolio-vault` Obsidian vault.
