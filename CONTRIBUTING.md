# Contributing

Workflow: issue, pull request, merge.

1. Open an issue (bug, feature or task template).
2. Create a branch from `main` named `<issue-number>-short-name`.
3. Commit your work, then run `pnpm check` and `pnpm build`.
4. Open a PR that includes `Closes #<issue-number>`.
5. Merge the PR when checks pass. Merging to `main` deploys to GitHub Pages.

Do not push directly to `main`.
